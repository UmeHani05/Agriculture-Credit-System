# Agriculture-Credit-System
## Overview

The Agricultural Credit System is a database-driven application designed to support risk-based lending for farmers. It centralizes farmer, loan, invoice, and transaction data to improve credit assessment, reduce fraud, and enhance financial decision-making.

## Objectives
Enable structured storage of agricultural and financial data
Support risk-based loan approval
Track invoices and overdue payments
Detect suspicious financial transactions
Provide reporting and analytics
### Features
Farmer registration and land record management
Loan application, approval, and repayment tracking
Risk score calculation based on historical data
Invoice creation, payment tracking, and status updates
Invoice aging analysis (current, 30/60/90+ days overdue)
Transaction logging and monitoring
Fraud detection and alert management
Reporting for loans, payments, and fraud cases
Role-based access control
